# Баталгаажуулалт: finance_combined

**Домэйн**: Санхүү / Finance
**Салбар**: Санхүүгийн тайлан, Зарлагын шинжилгээ
**Хүснэгтийн төрөл**: transaction

## Хүснэгтийн тайлбар
finance_combined хүснэгт нь байгууллагын санхүүгийн бүх гүйлгээний нэгдсэн мэдээллийг агуулна. Энэ нь дараах үндсэн 6 ангилалаас бүрдэнэ: Зарлага, Үйл ажиллагааны орлого, Дотоод шилжүүлэг, Зээлийн орлого, Эздийн зээл, Бусад орлого.

## Баганын тайлбар
- **date**: Гүйлгээний огноо
- **customer**: Гүйлгээ хийгч/харилцагчийн нэр
- **amount**: Гүйлгээний дүн (MNT)
- **category**: Үндсэн ангилал (Зарлага, Үйл ажиллагааны орлого, гэх мэт)
- **subcategory**: Дэд ангилал (Цалин, Төсөл, Маркетинг, гэх мэт)
- **description**: Гүйлгээний дэлгэрэнгүй тайлбар

## Ангиллын бүтэц
- **Зарлага** (Expenses): Цалин (77.8M₮), Төсөл (52.6M₮), Маркетинг (33.8M₮), Түрээс (25.2M₮), Нийтийн үйлчилгээ (13.2M₮), Бусад зарлага (11.3M₮)
- **Үйл ажиллагааны орлого** (Operating Income): 167M₮
- **Дотоод шилжүүлэг**: P&L-д орохгүй, зөвхөн мөнгөн урсгал

### Тэргүүлэх 5 бизнесийн асуулт
1. Энэ сарын нийт зарлага хэд вэ?
2. Цалингийн зарлага нийт зарлагын хэдэн хувийг эзэлж байна вэ?
3. Орлого, зарлагын зөрүү (ашиг/алдагдал) хэд вэ?
4. Аль ангилалд зарлага хамгийн их өссөн бэ?
5. Сүүлийн 3 сарын зарлагын чиг хандлага ямар байна вэ?
